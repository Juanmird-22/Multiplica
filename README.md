# Multiplica

Aplicación web educativa para aprender a administrar el dinero y explorar formas responsables de hacerlo crecer.

## Ejecutar
1. Descarga o descomprime el proyecto.
2. Abre `index.html` en Google Chrome, Edge o Firefox.
3. No necesita servidor ni instalación de Node.js.

## Tecnologías
- HTML5
- CSS3
- JavaScript (ES6)

## Funciones
- Dashboard financiero.
- Presupuesto.
- Registro de ingresos y gastos.
- Ideas de emprendimiento con simulación.
- Metas financieras.
- Progreso.
- Sección educativa.
- Diseño responsive para computador y celular.

Nota: las ganancias mostradas son únicamente estimaciones educativas y no constituyen una promesa de rentabilidad.
